# Dify 导入与试跑

三个文件均为 Dify DSL 0.7.0，来自本机项目或其演示版本。开发和验收使用自托管 Dify 1.20.0。

## 先试离线演示

1. 在 Dify Studio 选择 **创建应用 → 导入 DSL 文件**，导入 `workflows/preview-demo.dify.yml`。
2. 打开 **试运行**，在业务路线选 `auto`。填入下表任意一句需求。
3. 查看分流结果及其固定案例摘要。示例只执行本地代码，使用与完整图相同的意图规则。

| 输入 | 预期出口 |
| --- | --- |
| 参考这个视频，帮我的模特试穿这几套衣服。 | 服装工作流，显示款序和拍点摘要 |
| 保留原片的店员，换掉手里的杯子。 | 商品替换。历史摘要显示 2 张商品参考图、0 张人物参考图和 2 个已核对镜头。 |
| 把原片中人物和他手上的产品都换掉。 | 联合替换，显示商品图和人物图绑定 |
| 把原片的主持人换成这位演员，保留商品。 | 人物替换，显示人物参考图与预检状态 |
| 用这些素材帮我做条视频。 | 提示澄清需求 |

上述五组输入已在本机 Dify 的试运行中验证。

## 查看完整工作流

导入 `workflows/commerce-video.dify.yml`，可以检查全部节点、连接、提示词编译、角色校验和输出映射。图中 HTTP 节点连接本机媒体服务。要执行真实生成，请在自己的环境配置服务与凭据，并把服务地址调整到 Dify 能访问的位置。

| 服务 | 工作流调用与交付 |
| --- | --- |
| 图像与素材服务（8766） | `/api/model-reference` 处理模特参考，`/api/garments` 处理衣鞋，`/api/tryon` 执行试穿。另有素材库读取与已完成试穿的登记接口。 |
| 参考片分析制备（8794） | `/media/prepare` 接收原片、试穿和场景资料，返回分析证据或待复核条目。接入画面分析、音乐拍点及连续片段的视觉分析。 |
| 原片精编与视频交付（8795） | `/media/replacement/prepare` 做原片预检，`analyze` 和 `generate` 分别用于策划与提交，`status/{id}` 回查。服装生成使用 `/media/render` 与任务等待接口。 |

视频生成的工作依赖图像编辑服务、视频分析工具和供应商模型。原片编辑接入光序工作台。导入完整图不会安装这些服务。离线演示可以在配置完整服务之前检验分支与输出结构。

### 从不同入口开始

- 新服装任务可以上传模特及商品照，走完整素材准备和参考分析。
- 已确定试穿图时，从试穿图或素材库接入，重新分析本次参考片。
- 原片编辑需要原片以及商品或人物图。初次准备后可按编号接续分析、审阅、提交和回查。
- 默认先准备提示词或制作表。为生成指定独立确认和任务标识后，才提交付费视频请求。
